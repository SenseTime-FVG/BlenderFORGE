# Static Material Snapshot

This folder contains the derandomized Infinigen material runtime used by
BlenderFORGE, with sampled shader defaults replaced by constants. Files were
copied without changing their source bytes.

Upstream: Infinigen, copyright Princeton University and the contributors named
in individual source files. See the included LICENSE. The surrounding Infinigen
installation, including its separately licensed dependencies, remains required.

In the BlenderFORGE repository, installation instructions are in
`src/BlenderFORGE_Data_Pipeline/material/infinigen/README.md`; source hashes and provenance are in
`src/BlenderFORGE_Data_Pipeline/material/infinigen/materials_static_manifest.json`. This snapshot does not include
the original development scripts or their broader generated catalog.
